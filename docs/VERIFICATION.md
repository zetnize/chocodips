# Проверка Choco Dips

Дата: 4 ноября 2026. Среда: Windows, Node.js 24.21.0, Chromium, локальная производственная сборка `next start`.

## Сборка и код

- `npm run lint` — успешно, без ошибок и предупреждений.
- `npm run typecheck` — успешно.
- `npm run build` — успешно: главная, меню, политика, 404, OG-изображение, robots, sitemap; API заявки — серверный маршрут.
- `npm run dev` — запускался и использовался при разработке.
- `npm start -- --hostname 127.0.0.1` — производственный сервер запускался и использовался для итоговых проверок.

## Адаптивность

На ширинах viewport 390, 768, 1024 и 1440 px проверены главная и меню. Во всех восьми случаях ширина документа совпала с доступной шириной окна, горизонтальной прокрутки нет. На каждой странице один H1. `/menu#coffee` открывает нужный раздел, активный чип «Кофе», заголовок не перекрыт липкой панелью. На главной все изображения загрузились без ошибок. Скриншоты: `output/playwright/home-{width}.png`, `output/playwright/menu-{width}.png`.

## Взаимодействия

- Мобильная навигация: открытие, 12 последовательных нажатий Tab без выхода фокуса наружу, блокировка фона через inert и scroll lock, Esc, возврат фокуса на бургер, переход по ссылке галереи.
- Слайдер: автопереключение, пауза при наведении, отдельная кнопка паузы, клавиатурные стрелки, свайп через Pointer Events.
- Категории: прокрутка ленты кнопкой на мобильном; на широком экране стрелка открывает всё меню.
- Галерея: открытие lightbox, стрелка клавиатуры, свайп, Esc, возврат фокуса на исходную фотографию.
- Меню: поиск по составу; регистронезависимый запрос `ЧЕРНЫЙ` находит позиции с «чёрный»; очистка поиска; пустое состояние без ссылок на отсутствующие категории; sticky-чипы и автоматическая видимость активного чипа.
- Карточка блюда: состав и аллергены, закрытие по Esc и фону, возврат фокуса.
- Бронь: ошибки обязательных полей, маска `89990000000 → +7 (999) 000-00-00`, согласие, отправка в деморежиме, достоверное сообщение о деморежиме, закрытие и возврат фокуса.
- Reduced motion: контент виден сразу, autoplay отключён; проверено с эмуляцией `prefers-reduced-motion: reduce`.
- В итоговой производственной браузерной сессии — 0 ошибок и 0 предупреждений консоли; ошибок гидратации не обнаружено.

## API

`node scripts/check-api.mjs` выполнен успешно. Проверены:

- успешная демозаявка с браузерным Origin;
- 8 случаев ошибок полей: короткое/длинное имя, телефон, отсутствие согласия, honeypot, несуществующая дата, время вне диапазона, слишком много гостей;
- некорректный JSON и тело больше 4096 байт;
- отклонение чужого Origin;
- rate limit: шестой запрос за минуту получает 429;
- публичные маршруты — 200, неизвестная страница — 404.

## Что осталось настроить владельцу

Телефон, социальные ссылки, production URL, настоящее меню, фотографии 16 позиций и юридические сведения об операторе. Изображения на главной сгенерированы; полный набор промптов и назначения файлов — в `docs/IMAGE-PROMPTS.md`.

Доставка в Telegram не проверялась: реквизиты не настроены, внешние сообщения не отправлялись. Распределённый rate limit не настроен. Публикация на Vercel, тесты Safari/Firefox и проверка на физических мобильных устройствах не выполнялись. Проверка свайпов использовала синтетические Pointer Events в Chromium.
